# 每秒拍照

macOS 菜单栏定时拍照 App。可只保存照片，也可框选照片中的仪器读数，在数值进入设定范围或命中指定数字时发送邮件。源码按 MIT 许可开放。

## 支持范围与安装

- **Apple 芯片（arm64）、macOS 13 或更新版本。**发布包不包含 Intel 版本。
- 需要 imageSnap 和 **Python 3.9 或更新版本**。App 启动时自动查找用户电脑上可用的 Python 3，不绑定开发者电脑的解释器或某个 Python 小版本；数字识别使用 macOS 自带的 Vision。尚未安装依赖时，可先安装 [Homebrew](https://brew.sh/)，再运行：`brew install imagesnap python`。
- 从 GitHub Releases 下载 `每秒拍照-macos-arm64.zip`，解压后将 `每秒拍照.app` 拖入“应用程序”。ZIP 内也附有本说明和 MIT 许可。
- 目前没有 Apple Developer ID，发布包是临时签名，**没有经过 Apple 公证**。首次打开若被 macOS 拦截，请确认下载来源可信后，在“系统设置 → 隐私与安全性”中找到该 App 的“仍要打开”，按系统提示继续。无需关闭系统的整体安全检查。参见 [Apple 官方说明](https://support.apple.com/zh-cn/guide/mac-help/mh40617/mac)。首次使用还需允许摄像头权限。

当前 ZIP **不是零依赖的即下即用包**：用户电脑上必须已有 imageSnap 和兼容的 Python 3；若已经安装，则无需重复安装 Homebrew 软件。若运行时提示找不到依赖，请检查安装路径和版本。

## 使用

1. 启动 App，输入拍照间隔（秒）；有多个摄像头时选择设备。随后选择照片保存位置：使用默认位置、本次另存到指定文件夹，或更改默认位置。初始默认位置为 `~/Pictures/每秒拍照/`；修改后会记住，临时另存不会改变默认位置。App 会试拍 3 张，用于估算单张照片大小和所选磁盘可拍时长。
2. 选择 **仅拍照**，或 **拍照并监控数字**。选择监控时，App 用最后一张试拍照片显示预览；在照片上拖出、移动和缩放方框，只框住一个目标读数。可放大预览后精细调整。若摄像头尚未对准，先调整位置，再点 **重新拍照**；确认读数窗口中的 **重新拍照并框选** 也会拍新照片，不会沿用旧画面。
3. 监控模式下填写提醒条件：`10~20` 是含边界的范围，`49` 是单个数字，`49、199、299` 是多个数字。支持负号和小数，例如 `-12.5~0.5`。单个数字按数值相等判断；读数有波动时宜用范围。
4. 监控模式首次使用需配置 SMTP 发件邮箱、客户端授权码和收件邮箱。支持 163 邮箱快速设置，也可填其他 SMTP 服务器。授权码存放在 macOS 钥匙串，普通设置文件不含授权码。以后可在启动窗口或拍摄中的菜单栏修改邮件设置。**仅拍照无需配置邮箱。**
5. 输入总时长（分钟）。窗口显示按当前剩余磁盘空间、试拍照片大小和 50% 波动余量估算的最长时长，并为系统预留 10 GiB。估算会随磁盘空间变化，并不能保证实际可拍满该时长。
6. 拍摄时点击菜单栏 **📷 拍照中**，可以打开照片文件夹或提前停止。每次会话位于所选文件夹的 `日期时间-进程号/` 子目录；JPEG 直接陆续出现在该目录，`capture.log` 记录每段拍摄过程。监控模式另有 `recognition.csv` 和 `monitor.log`。

命中条件需要连续两张照片得到相同的匹配结果才发一封提醒邮件，邮件会**附上触发时的原始照片**。读数离开范围、再连续两张回到范围时可再次提醒。识别不出数字、方框内有多个数字或邮件发送失败，都可以在日志中检查。照片始终保存在本机；仅启用邮件提醒后，触发照片才经用户配置的 SMTP 发给收件人。App 不使用分析服务。

## 运行边界

- 拍照间隔由摄像头和系统负载决定，不保证严格到毫秒；分段重启 imageSnap，每段最多 60 张，以控制长时间运行时的内存增长。
- 1.9.4 起，偶发失败造成的原始照片编号跳号会被重新编为连续编号，避免监控程序漏掉后续照片；邮箱设置窗口也会阻止同时打开多份。提前停止或拍摄异常的原因请查看该次目录的 `capture.log`。
- 容量估算以当前磁盘空间为准，拍摄时每段会再检查。其他程序写入、照片内容变化或摄像头故障，都可能让拍摄提前停止。
- 模糊、反光、遮挡、过曝、数码管闪烁和框选不准都会造成漏识别或误识别。正式使用前应短时试拍，并核对 `recognition.csv`。**邮件提醒不应作为设备安全联锁或唯一报警手段。**
- 当前版本尚未完成带识别的连续 4–6 小时整段验证。构建与短时实际摄像头拍摄已验证；长时可靠性应在目标电脑上进一步试运行。

## 从源码构建

在 Apple 芯片 Mac 上安装 Xcode Command Line Tools（`xcode-select --install`），然后运行：

```bash
cd camera-automator
./build.sh
```

构建产物位于 `dist/arm64/每秒拍照.app` 和 `dist/arm64/每秒拍照-macos-arm64.zip`，另有 `.sha256` 校验文件。构建使用 ad-hoc 签名，不等于 Developer ID 签名或公证。`./install.sh` 可将构建好的 App 安装到 `~/Applications`；若目标位置已有同名 App，脚本会停止，避免覆盖。

源码中 `AppLauncher.swift` 为原生启动器，`capture_with_imagesnap.sh` 管理拍摄，`CaptureMenu.swift` 管理菜单栏，`RegionPicker.swift` 和 `InstrumentOCR.swift` 实现框选与识别，`monitor_instrument.py` 处理提醒逻辑，`configure_mail.sh`、`MailSecret.swift`、`mail_delivery.py` 处理邮箱设置。旧版 Automator 原型和编译产物不属于公开源码。

## 隐私与许可

照片、日志、默认保存位置和邮箱设置保存在本机；SMTP 授权码保存在钥匙串。准备公开仓库或反馈问题时，请勿上传自己的照片、日志中的个人信息或邮箱设置。项目源码按 [MIT License](LICENSE) 授权；imageSnap 和 Homebrew 是独立安装的第三方程序，遵循其各自许可。
